# 📝 Tasks.io

A simple, lightweight **task management web app** that runs entirely in your browser.  
No database, no server — just **pure JavaScript + Local Storage**.

🔗 **Live Demo:** [Tasks.io](https://abdelrahmanmohmmed.github.io/tasks.io/)

---

## ✨ Features

✅ **Add tasks** — Write a new task and save it instantly.  
✅ **Persistent storage** — Your tasks stay saved even if you close your browser or restart your PC.  
✅ **Mark tasks as completed** — Keep track of what you’ve finished.  
✅ **Delete all tasks** — Quickly clear everything when you’re done.  
✅ **Fully client-side** — No backend or database required.

---

## 🛠️ Tech Stack

- **HTML5** – Structure  
- **CSS3** – Simple styling  
- **JavaScript (Vanilla)** – Logic & Local Storage  

> This project uses **Local Storage** to save tasks securely on the user's own device.  
> There is no server or external database involved.

---

## 🚀 How to Use

1. Open the website: [https://abdelrahmanmohmmed.github.io/tasks.io/](https://abdelrahmanmohmmed.github.io/tasks.io/)  
2. Type your task in the input field.  
3. Click **Add Task** (or press Enter).  
4. ✅ Mark tasks as complete when done.  
5. 🗑️ Use **Delete All** to clear all tasks.
